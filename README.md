# ⚽ 足球竞彩 AI 分析系统

> 基于多维数据的智能足球分析平台，同步中国竞彩赛事

## 核心功能

### 📊 数据分析维度
| 维度 | 说明 | 权重 |
|------|------|------|
| 近期状态 | 近5-10场胜负平走势 | 20% |
| 历史交锋 | 两队直接对话记录 | 15% |
| 主客场表现 | 主队主场 vs 客队客场 | 15% |
| 联赛排名 | 当前积分榜位置 | 10% |
| 进攻火力 | 场均进球、射门、射正 | 10% |
| 防守能力 | 场均失球、零封场次 | 10% |
| 伤停情况 | 关键球员缺阵影响 | 10% |
| 赔率分析 | 多家机构赔率对比 | 10% |

### 🎯 预测输出
- 胜平负概率（主胜/平/客胜）
- 比分推荐（3个最可能比分）
- 进球数预测（大/小球）
- 让球分析（亚盘参考）
- 信心指数（1-5星）

### 📅 竞彩同步
- 实时竞彩赛程
- 竞彩赔率对比
- 热门赛事推荐

## 技术栈
- 前端：HTML/CSS/JS（单文件，零依赖）
- 数据：多源 API 聚合
- 分析：前端 JavaScript 统计引擎
- 部署：GitHub Pages（静态）
